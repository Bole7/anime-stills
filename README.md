# 截帧 · Anime Stills

一个近期日本动画截图的分享站。打开就是一圈会缓慢自转的**环幕**，把喜欢的画面停下来看。

> Web 全栈开发课程作业 · 王博乐

---

## 一、设计定调

| 项 | 决策 |
|---|---|
| **目的** | 把散在相册里的动画截图，变成一个能"翻着看"的地方 |
| **调性** | 亮色「纸感画廊」—— 暖白纸底、墨黑铅字、唯一朱红强调色 |
| **展示字** | Cormorant Garamond（拉丁衬线）+ 中文宋体栈 |
| **正文字** | 系统黑体栈（PingFang SC / 微软雅黑） |
| **元数据字** | JetBrains Mono（帧号、日期、标签统统一把等宽尺） |
| **记忆点** | 巨大的 3D 环幕：8 张画面围成圆柱，自己慢慢转，可以拖可以翻 |

配色只用三档：`--paper #F4F2EC` 纸底 / `--ink #16150F` 墨字 / `--accent #C4432B` 朱红。
朱红全站只出现在帧号、当前帧刻度、"停下来"三个字这类关键位置，其余一律黑白。

## 三、怎么运行

**方式一：直接打开。** 双击 `index.html` 即可，不需要任何构建工具、不需要联网
（字体走 Google Fonts，加载不到会优雅回退到系统衬线体）。

**方式二：本地服务器。**

```bash
python -m http.server 8080
# 然后访问 http://127.0.0.1:8080
```

## 四、功能清单

**环幕轮播（首屏）**

- CSS 3D 圆柱：8 个面板 `rotateY(i·45deg) translateZ(R)` 围成环，`perspective` 做景深
- 半径不是写死的：先定"屏幕上想看到多大"，再由透视公式反推面板实宽与圆柱半径
- 自动旋转（6°/秒）、拖拽旋转（带惯性衰减）、松手吸附到最近一帧
- 键盘 `←` `→` 翻帧，`空格` 暂停/继续自动旋转
- 触控板横向滑动可以转，纵向滚动仍然留给页面（不劫持滚动）
- 非当前帧盖一层纸色遮罩"未点亮"，当前帧才亮起来 —— 亮色主题下的聚焦手法

**目录网格**

- 53 张全部铺开，`auto-fill` 自适应列数
- 按主色调自动归档的筛选器：全部 / 夜色 / 明亮 / 暖调 / 冷调 / 低饱和
- 标签不是手打的：构建时用 Python 对每张图做 HSV 统计（明度、暖冷像素占比、饱和度）自动生成

**灯箱**

- 点击任意画面放大，图片下方一条信息栏显示帧号、日期、色调
- `←` `→` 在**当前筛选结果内**翻页，`Esc` 关闭，焦点自动回到触发元素
- `Tab` 键在灯箱内循环，不会跑到底层页面

**其他**

- 首屏一次编排好的入场序列（4 组，60/180/300/420ms 错峰）
- 滚动触发的 `IntersectionObserver` 入场，卡片按 4 档错峰
- 导航栏滚过 12px 后转为毛玻璃条
- 全部动效在 `prefers-reduced-motion: reduce` 下一律关闭

## 五、关于素材

素材是个人追番时的收藏截图（以《电锯人》为主），共 53 张，均为 1919×1079 原始比例。

原图右下角带平台水印，处理时用**局部取样修补**（取同高度左侧背景覆盖并羽化边缘）去掉水印，
而不是直接裁掉底部 —— 保住了完整的 16:9 构图。画面里的字幕保留了下来，那是截图的一部分。

WebP 三档尺寸由 Pillow 批量生成，全部素材合计约 3.3 MB。

> 仅用于课程作业的学习与展示，不作任何商业用途。

## 六、自检结果

| 关卡 | 结果 |
|---|---|
| 展示字与正文字 | Cormorant Garamond + 宋体栈 + JetBrains Mono，均不在默认字体禁用清单内 |
| 配色 | 一主色 + 一强调色（朱红），无白底紫渐变 |
| 对比度 | 三级文字对纸底分别为 16.7:1 / 7.4:1 / 4.8:1，全部过 WCAG AA |
| 入场序列 | 4 组错峰（60/180/300/420ms），非零散微交互 |
| 降级动效 | `prefers-reduced-motion: reduce` 下全部动画关闭 |
| 氛围层 | 纸纹噪点（SVG feTurbulence）+ 双径向渐变光晕 |
| 状态覆盖 | 默认 / 悬停 / 聚焦可见 / 禁用不适用 / 加载 / 空态（筛选无结果时） |
| 响应式 | 1440 / 390 两档实测无横向溢出、无构成崩坏 |
| 可访问性 | 语义地标、唯一 h1、跳转链接、44px 点击目标、键盘全可达、焦点陷阱 |
| 本地可运行 | 双击 `index.html` 即可，无缺失资源、无占位符 |

## 七、技术说明

- 纯原生 HTML / CSS / JavaScript，**零依赖、零构建**
- 脚本用 IIFE 封装，不用 ES Module —— 因为 `file://` 协议下模块加载会被跨域策略拦截，
  这样可以保证作业发给老师后双击就能看
- 数据以 `.js` 文件而非 `.json` 注入，原因同上（`fetch` 本地文件同样被拦）
